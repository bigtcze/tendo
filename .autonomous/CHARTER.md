## Product thesis
Families carry obligations mentally because calendars require concrete dates and generic todo apps optimize for work and task scheduling. Tendo holds persistent household obligations, surfaces them when they deserve attention, and never assumes that time passing means the work happened.

## Core promise
"Remember less. Nothing disappears until it is actually done."

## Success
A real household can run Tendo self-hosted, without mandatory external SaaS, and use it for weeks for one-off and repeating obligations around people, home, vehicles, pets and custom subjects. Multiple households per person and a clear household admin model are supported (PRODUCT "Identity and households").

## Platform principle
The domain and API are the durable core. Future AI, documents, Nextcloud, calendar, inbox, notifications and other clients attach through stable application and API boundaries instead of bypassing them (ROADMAP "Extension rule").

## Non-goals
- project management software
- calendar replacement
- generic chore chart
- enterprise dashboard
- household ERP
- native mobile application
- AI agent or general autonomous household agent
- notification delivery subsystem
