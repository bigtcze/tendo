# Visual-test font environment

The product now ships **Inter Variable** as a self-hosted webfont (`@fontsource-variable/inter` 5.3.0, SIL Open Font License 1.1; see `docs/design/v4-design-system.md`). Visual Chromium loads the app's own hashed `woff2` files from the production build, so captures render the real product font rather than a system substitute.

The Liberation Fonts 2.x TTF files from Debian's `fonts-liberation` package (`/usr/share/fonts/truetype/liberation`, installed package version 1:2.1.5-3 on the capture host) remain committed as the **system fallback only** — the family substituted when Inter itself is unavailable (for example while a font request is in flight, or if a future regression drops the `@font-face`). Source: https://github.com/liberationfonts/liberation-fonts. License: SIL Open Font License 1.1, text included as `OFL-LICENSE.txt` from `/usr/share/doc/fonts-liberation/copyright`.

`fonts.conf` reads only this sibling directory and aliases the product's system fallback families (`system-ui`, `ui-sans-serif`, `sans-serif`, …) to Liberation Sans, and the Tailwind defaults `serif`/`monospace` to Liberation Serif/Mono. `FONTCONFIG_FILE` is scoped to the visual Playwright child process by the native runner, so application CSS and normal browser tests are untouched. The config uses a relative font directory, and can therefore travel with the repository. Chromium's default fontconfig fallback is replaced for this process.
