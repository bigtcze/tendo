First stable release of Tendo, a self-hosted shared list for the things a household needs to remember.

Tendo is built for obligations that have no fixed date or that come back every few months: the car inspection, a child's dentist check-up, replacing the water filter. An item stays on the list until someone marks it done. Nothing disappears just because a date passed.

## What's in 1.0

- **Items** for one-off tasks, with an optional date from which they need attention. Without a date, an item needs attention now.
- **Repeat** on a fixed schedule (the next date keeps its cadence even if you finish late), or counted from the day you last did it. When adding a repeating item, you can enter when you last did it to set the first date.
- **People and things.** Each item belongs to someone or something: a family member, the home, a vehicle, a pet, or anything else. A person can be linked to their Tendo account.
- **Status.** Mark an item as in progress, waiting on something, or paused. The home screen shows what needs attention first, then what is being handled, then what is coming up.
- **History.** Every completion is recorded. The latest one can be undone if it was marked by mistake.
- **Household members.** The owner invites others with a private link. Tendo sends no email and needs no outside service. Any member can be named as the person looking after an item.
- **Sign-in** with a local password, and optionally through an OpenID Connect provider such as Pocket ID.
- English and Czech interface, for phones, tablets, and computers.
- Versioned REST API under `/api/v1`, described in `api/openapi.yaml`.

## Install

These commands are for Linux with GNU sed. You need Docker Engine with the Docker Compose plugin 2.23.1 or newer, curl, and OpenSSL.

```sh
mkdir tendo
cd tendo
curl -fsSLO https://github.com/bigtcze/tendo/releases/latest/download/compose.yaml
umask 077
curl -fsSL -o .env https://github.com/bigtcze/tendo/releases/latest/download/example.env
sed -i \
  -e "s/^POSTGRES_PASSWORD=.*/POSTGRES_PASSWORD=$(openssl rand -hex 32)/" \
  -e "s/^TENDO_DATABASE_PASSWORD=.*/TENDO_DATABASE_PASSWORD=$(openssl rand -hex 32)/" \
  -e "s|^TENDO_SETUP_TOKEN=.*|TENDO_SETUP_TOKEN=$(openssl rand -base64 32)|" \
  .env
docker compose up -d --wait
```

Tendo then runs at `http://localhost:8080`. The [installation guide](https://github.com/bigtcze/tendo/blob/v1.0.0/docs/admin/install.md) covers first sign-in, and the [reverse proxy guide](https://github.com/bigtcze/tendo/blob/v1.0.0/docs/admin/reverse-proxy.md) covers HTTPS access from other devices.

## Image

`ghcr.io/bigtcze/tendo`, for `linux/amd64` and `linux/arm64`.

| Tag | Follows |
| --- | --- |
| `latest` | The newest release. This is the default in `compose.yaml`. |
| `v1` | The newest 1.x release. Never moves to 2.0. |
| `v1.0` | The newest 1.0.x release. |
| `v1.0.0` | This release only. |

Set `TENDO_VERSION` in `.env` to choose the tag. To avoid an unplanned major upgrade, use `v1`.

## Upgrading from a Git checkout

If you installed Tendo from `main` before this release, check that `docker compose version` reports 2.23.1 or newer, back up ([how](https://github.com/bigtcze/tendo/blob/v1.0.0/docs/admin/backup-restore.md#back-up)), then run in the same directory:

```sh
git pull --ff-only
docker compose pull
docker compose up -d --wait
```

Your data stays in place. Do not move the installation to a directory with a different name: Compose names the data volume after the directory. For later updates, see the [update guide](https://github.com/bigtcze/tendo/blob/v1.0.0/docs/admin/update.md).

## Not included

- Notifications or reminders outside the app.
- More than one household per account in the interface.
- Password reset. Keep passwords in a password manager.
- TLS. Tendo serves HTTP and expects a reverse proxy in front of it; tested configurations for Caddy, Nginx, and Traefik are included.
- Running under a URL path prefix. Tendo needs its own hostname or subdomain.

## Assets

- `compose.yaml`: Compose file for PostgreSQL 18 and Tendo.
- `example.env`: settings template. Save it as `.env`.
