Tendo 2.0 makes the household list easier to read and easier to search, even when it holds hundreds or thousands of items. Your data, your settings, and the way items repeat stay the same.

## What's new in 2.0

- **Home shows what needs attention first.** Groups are built from the whole household list, not only from the items loaded so far. Each heading shows how many items the group has. Items without a date come first, then the earliest dates. **Show more** says how many items are left. Each group shows up to 100 items on Home, then links to **See all … in All items**. When two or more groups have items, **Group overview** links at the top jump to each group.
- **More detail on each Home row.** A Home row shows its attention date, when the item was last done, and who is looking after it. A repeating item also says whether it **keeps planned dates** or is **counted from when it’s done**. **Done** on each row is now a quieter button, so **Add item** stays the main action.
- **All items: search and filters.** A new screen lists every item in the household, including done and archived items. Search finds words in titles and notes, ignoring upper/lower case and Czech accents. You can filter by status, by person or thing, by who is looking after the item, and by whether it repeats. The counts are for every matching item, not only the page you are looking at. The list moves one page at a time. Your search, filters, and page stay in the address, so **Back** from an item returns to the same page.
- **Navigation on every screen.** Home, All items, People and things, Members, and Account are at the top of every household screen.
- **Long lists stay fast.** People and things, members, invitations, and an item's completion history load one page at a time. **Older**, **Newer**, and **Latest** reach every past completion of an item.
- **Clearer states.** Screens show when they are loading and offer **Try again** when something cannot be loaded. If your session ends, the sign-in screen explains that you need to sign in again. If the sign-in options cannot be loaded, you can try again, and password sign-in still works.
- **Accessibility.** Automated checks cover keyboard use, visible focus, contrast, and touch target sizes across the main screens. Layout checks emulate 200 % and 400 % page zoom, and household screens and forms are checked with reduced motion. Form field borders are easier to see, and the Repeat switches have larger touch targets. No screen-reader user has tested this release, and these checks are not a formal accessibility certification.
- **One design across the app.** Text sizes, spacing, and page layout are now the same on every screen, from sign-in to account settings. The interface works on small phones, tablets, and computers, in English and Czech.

## Updating from 1.x

Your data is kept, and no new settings are required. Back up first ([how](https://github.com/bigtcze/tendo/blob/v2.0.0/docs/admin/backup-restore.md#back-up)). If `TENDO_VERSION` in `.env` is `v1` or `v1.0.0`, change it to `v2` or `latest`. Then follow the [update guide](https://github.com/bigtcze/tendo/blob/v2.0.0/docs/admin/update.md#updating-from-1x-to-20).

The update changes the database once:

- It installs the PostgreSQL extensions `unaccent` and `pg_trgm` for search. The published `compose.yaml` migrates as the PostgreSQL administrator, which can install them. If you use your own PostgreSQL with a less privileged migration role, that role must be allowed to install these two extensions. Both must be installed in the `public` schema; if either is already installed in another schema, the update stops, so move it first.
- It adds sorting and search indexes and fills a new search column in every existing item. With many items the update takes longer than usual; Tendo starts only after the migration has finished.

To go back to 1.x you need the backup you took before updating; see [Go back to an earlier version](https://github.com/bigtcze/tendo/blob/v2.0.0/docs/admin/update.md#go-back-to-an-earlier-version).

## For API clients

`/api/v1` stays compatible: requests that worked with 1.0 return the same results. New optional features, all described in `api/openapi.yaml`:

- Item list filters `subjectId`, `responsibleUserId` (or `unassigned`), `workflowState`, `attention`, `recurring`, text search `q`, `sort=attention_on`, and the `attentionDate` freshness guard.
- `GET /api/v1/households/{householdId}/items/summary` returns counts for the whole matching list.
- Repeated `id` parameters on the subject list, and `order=newest` on an item's completion history.

Cursors from the new queries are tied to the query that produced them. See the [API notes](https://github.com/bigtcze/tendo/blob/v2.0.0/docs/development/api.md#cursor-pagination).

## Not included

- Notifications or reminders outside the app.
- More than one household per account in the interface.
- Password reset. Keep passwords in a password manager.
- TLS. Tendo serves HTTP and expects a reverse proxy in front of it.
- Running under a URL path prefix.

## Assets

- `compose.yaml`: Compose file for PostgreSQL 18 and Tendo.
- `example.env`: settings template. Save it as `.env`.
