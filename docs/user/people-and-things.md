# People and things

Items can be added for a person or thing. See [Items](items.md) for adding, repeating, and completing them.

"People and things" is the list of who and what your household looks after: a child, your home, the car, a pet. Open it with **People and things** in the navigation at the top of every household screen.

## Add one

Select **Add**, type a name (1 to 100 characters, plain text), and choose what it is:

- Person
- Home
- Vehicle
- Pet
- Other

Select **Add** again to save. The new entry appears in the list. If Tendo can’t confirm the save, select **Check again** to safely retry.

A person does not need an account. Adding "Anička" creates an entry in your household, not a login, so a child can be listed without signing in anywhere.

If a person is also a household member, you can optionally choose their account in **Their account in Tendo**. This is only a label to help everyone recognise who is who; it does not change what anyone can see. To clear the link, select **Edit**, choose **No linked account**, then select **Save**. Changing the entry to another type clears it automatically.

## Long lists

The list shows one page at a time. Use **Next page**, **Previous page** and **First page** to move through it; the page number is shown between the buttons. The same buttons work in the archived list.

## Rename or change the type

Select **Edit** next to an entry, change the name or type, and select **Save**. If someone else changed the same entry a moment earlier, Tendo shows the latest version so you can check it and save again.

## Archive and restore

Select **Archive** to move an entry out of the way. Tendo confirms it and offers **Undo**. Nothing is deleted.

To see archived entries, select **Show archived**. Select **Restore** next to one to bring it back, then **Back to the list** to return.

## Language

The screen is available in English and Czech. Switch the language in the footer.
