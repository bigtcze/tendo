Rows group equivalent assertions when exact IDs are listed. A Go test with internal subtests is cited by its parent only unless a named subtest was independently verified. IDs below are concrete source names (not wildcards). A checked assertion’s strength is noted; weak status-only/mock tests are not represented as end-to-end proof.

**Scenario class key:** H=happy; N=negative; B=boundary; S=state; C=concurrency; Sec=security; I=interrupted; R=retry. **Layers:** domain=unit; HTTP=handler/service tests; PG=real PostgreSQL integration; FE=Vitest (usually fake server, not backend proof); E2E=production-built UI + backend + isolated PostgreSQL; smoke=deployment/runtime script; contract=OpenAPI/generation checker.
