# V2.1 requirements-to-tests coverage matrix

**Snapshot:** inventory produced at `ba8cad1b114900463106a182b4c116468738c113`; historical reference check at `6e99e11`; gap statuses reconciled through `503c1c9` below. **Status:** living document; residuals are explicitly identified in row-specific notes and G12. **Produced:** source/spec/API/CI inventory; test symbols and UI/E2E titles below were checked by source grep/read. This document itself does not run suites: “present” means the test exists and is registered in the stated required layer; pass evidence is recorded only in the verification table at the end. Required-gate membership checked in `.github/workflows/required.yml` and `scripts/verify-local.sh`. CI=required job/layer, not claim that a specific named scenario is independently gated.

Rows group equivalent assertions when exact IDs are listed. Go test IDs are `path/file_test.go:TestName`; Vitest IDs are `file :: describe > it title`; Playwright IDs are `frontend/e2e/file.spec.ts :: title`; smoke IDs give script plus named operation/step where the script supplies it. A Go test with internal subtests is cited by its parent only unless a named subtest was independently verified. API operation rows are exhaustive by `api/openapi.yaml` operation inventory; response status details are intentionally summarized as classes rather than claiming each status is asserted. IDs below are concrete source names (not wildcards). A checked assertion’s strength is noted; weak status-only/mock tests are not represented as end-to-end proof.

**Scenario class key:** H=happy; N=negative; B=boundary; S=state; C=concurrency; Sec=security; I=interrupted; R=retry. **Layers:** domain=unit; HTTP=handler/service tests; PG=real PostgreSQL integration; FE=Vitest (usually fake server, not backend proof); E2E=production-built UI + backend + isolated PostgreSQL; smoke=deployment/runtime script; contract=OpenAPI/generation checker.
