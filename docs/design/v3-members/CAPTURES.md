# Members and invitations capture index

Production-build screenshots are produced by `frontend/e2e/ux-audit.spec.ts` and `frontend/e2e/audit/members.ts` through `scripts/e2e-smoke.sh`, with pinned Chromium and the real test API/database. Error and permission states are browser-stubbed. The non-owner captures use the real seeded audit-member account and the test service's paged membership data. Before captures are from detached `origin/main` at `96c33f1`; after captures are from this V3-12 worktree. Invite bearer links are masked in all link-state captures and must never appear unmasked in committed evidence. No human usability testing is claimed.

Commands (source the private test environment first):

```sh
source ~/.config/tendo-test/env
git worktree add --detach /tmp/opencode/v312-before 96c33f1
TENDO_UX_AUDIT_DIR=/tmp/opencode/v312-before-captures bash scripts/dev-exec.sh -- bash -c 'cd /tmp/opencode/v312-before && bash scripts/e2e-smoke.sh'
TENDO_UX_AUDIT_DIR=/tmp/opencode/v312-after bash scripts/dev-exec.sh -- bash scripts/e2e-smoke.sh
```
